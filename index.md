# Installing MySQL Server on Ubuntu: A Practical Reference

This project addresses the need to set up a reliable MySQL Server instance on Ubuntu, primarily to support an autoposting tool that logs metadata of social media posts. The goal is to establish a local database backend efficiently and reproducibly.

## Motivation

The impetus behind this setup is the requirement for a persistent data store to track metadata generated by an autoposting system. MySQL is chosen due to its widespread use, robustness, and compatibility with Ubuntu environments.

## Problem Statement

Manual installation of MySQL Server on Ubuntu can be error-prone and inconsistent, especially when relying on default package repositories that may not have the latest versions. This project consolidates the necessary steps to add the official MySQL APT repository, ensuring access to up-to-date packages and a smoother installation process.

## Implementation Details

### Repository Addition

The first step involves downloading the MySQL APT configuration package from the official MySQL site. This package configures the Ubuntu package manager to include MySQL's own repository.

```bash
sudo dpkg -i mysql-apt-config_w.x.y-z_all.deb
```

This command installs the repository configuration, where `w.x.y-z` corresponds to the version of the package downloaded.

### Package Installation

After adding the repository, the apt package index is updated, and the MySQL Server package is installed:

```bash
sudo apt-get update && sudo apt-get install mysql-server
```

This ensures the installation pulls from the newly added MySQL repository rather than the default Ubuntu repositories.

### Service Verification

Post-installation, it is critical to verify that the MySQL service is running correctly:

```bash
systemctl status mysql
```

This command provides the current status and confirms that the server is operational.

## Practical Considerations

- The installation instructions assume sudo privileges.
- Version numbers for the MySQL APT config package will vary; users must download the appropriate version.
- The MySQL service typically starts automatically after installation, but verification is necessary.

## Conclusion

This repository and its documentation serve as a concise, practical guide for setting up MySQL Server on Ubuntu using the official MySQL APT repository. It is designed to be a technical reference for developers returning to the project or setting up similar environments, emphasizing clarity and reproducibility over abstraction or embellishment.
